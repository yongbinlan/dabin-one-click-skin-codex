# Codex一键换肤——大斌

Windows x64 Codex 自定义图片换肤技能。

## 使用方法

下载或克隆本仓库后，双击：

```text
scripts/StartDabinSkin.bat
```

然后选择 PNG、JPG、JPEG、BMP 或 WebP 图片即可应用主题。

## 功能

- 支持自定义主题图片
- 支持 Windows x64 Codex
- 用户消息自动使用黑底白字
- 支持恢复 Codex 原生主题
- 不修改 Codex 程序文件、登录状态或账户配置
