# 大斌 · Codex 换肤使用教程

## 这是什么

这是一个原创的本地换肤 Skill。它把你选择的图片和一组高对比度样式注入当前运行的 Codex 主界面。它不修改 Codex 安装文件，不写入 `app.asar`，也不读取或上传账户、登录信息和聊天内容。

## 使用条件

- Windows 64 位；
- Node.js 22 或更新版本；
- Codex Desktop 已打开，并显示侧栏和输入框；
- 主题图为 PNG、JPG/JPEG、BMP 或 WebP，且不大于 8 MB。

## 图形界面操作

1. 打开 Codex 主界面。
2. 双击 `scripts/StartDabinSkin.bat`。
3. 点击“选择图片”，确认预览和文件名正确。
4. 点击“检查连接”。看到“已发现 Codex 主窗口”后，再点击“应用到 Codex”。
5. 回到 Codex 检查背景、侧栏和消息文字。用户消息应为深底白字，避免背景干扰阅读。

需要撤销时，在启动器点击“恢复原生”。这会移除样式并停止本地控制器。

## 用 Skill 调用

无需放进固定路径。下载或解压完整文件夹到任意本地位置后，可以直接双击 `scripts/StartDabinSkin.bat` 使用启动器。

如需在 Codex 对话中调用，请在 Codex 的 Skills 导入入口选择这个包含 `SKILL.md` 的文件夹。重新开启一轮 Codex 对话后，可使用以下说法：

```text
使用大斌一键换肤，将这张图片应用到 Codex。
```

```text
使用大斌一键换肤，检查当前主题是否真正生效。
```

```text
使用大斌一键换肤，恢复 Codex 原生界面。
```

## 命令行操作

在仓库根目录打开 64 位 Windows PowerShell：

```powershell
.\scripts\dabin-skin.ps1 -Action Check
```

使用图片：

```powershell
.\scripts\dabin-skin.ps1 -Action Apply -ImagePath "D:\Pictures\theme.webp"
```

查看实际注入状态：

```powershell
.\scripts\dabin-skin.ps1 -Action Status
```

恢复原生：

```powershell
.\scripts\dabin-skin.ps1 -Action Restore
```

## 如何确认成功

不要仅凭图片预览或启动器窗口判断。运行 `Status`，确认结果同时包含：

```text
mode: active
injected: true
controller: running
```

然后在 Codex 可见主界面确认背景已显示、文字可以清楚阅读。页面刷新后，本地控制器会再次注入；关闭 Codex 后它会等待，直到下次打开 Codex 主界面。

## 常见问题

### 检查连接失败

请先打开 Codex 的实际主界面。托盘图标、主题弹窗、登录页或纯空白页都不属于可注入的主窗口。确认侧栏和输入框出现后再点“检查连接”。

### 应用后没有背景

先运行 `Status`。若结果为 `pending`，请等待几秒后再查看；控制器会重试连接。若仍不是 `active`，保留启动器显示的具体错误，不要反复点击应用。

### 文字不清楚

本版默认将用户消息固定为深底白字，页面正文为浅色文字，并对侧栏与主面板添加深色半透明层。若个别 Codex 版本中的某个区域仍然看不清，请提供该区域截图，用于针对该页面结构调整选择器。

### 如何完全撤销

点击“恢复原生”或运行 `-Action Restore`。它会删除当前页的自研样式，不会触碰 Codex 的程序文件或账户设置。

## 隐私与版权

本地图片会被编码到本机 `runtime/state.json`，仅用于本机的运行时注入。该文件已被 Git 忽略。上传仓库前请确认未手动加入 `runtime/` 中的个人图片或状态文件，并确保主题图片拥有使用授权。
