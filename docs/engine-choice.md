# 引擎选择与更名范围

2026-09-23，v2.6.0。

本次公开更新沿用独立轻量引擎，统一展示名称为“大硕主题中心”。这是针对现有公开项目的发布选择，不是声称它在全部能力上优于其他引擎。

| 维度 | 本仓库独立引擎 | HeiGe 派生的本地主题引擎 |
|---|---|---|
| 主要能力 | 单图应用、连接检查、状态、恢复 | 内置及用户主题、页面菜单、更多生命周期管理 |
| 实现范围 | Windows x64、Node.js 22+、单个轻量控制器 | 更大的跨平台运行时及控制组件 |
| 与当前仓库兼容性 | 保留现有入口、技术标识与参数 | 替换需要单独的迁移、归属及回退验证 |
| 本次处理 | 更新名称、教程、Skill 元数据和启动器预览 | 不打包本机运行目录、不迁移其修复或素材 |

另一套引擎功能更丰富；本仓库目前的用途是简洁的本机图片换肤，并非完整主题库管理。因此保留现有实现，避免一次更名夹带运行时替换、计划任务或进程管理变化。两边版本号属于不同产品，不能直接比较数字判断新旧优劣。

上游 [HeiGe Codex Skin Studio](https://github.com/HeiGeAi/heige-codex-skin-studio) 的代码许可在检查时为 MIT。未迁移不是因为禁止复用；若后续采用，应保留上游版权和许可，独立核实图片素材使用范围，并完成迁移及目标平台验证，不能改名后宣称全部原创。

## 兼容与运行边界

- 显示名称：大硕主题中心。
- Skill 标识：`dabin-one-click-skin`；启动入口仍是 `scripts/StartDabinSkin.bat`。
- 仓库地址、控制器状态字段、环境变量及原版权署名不变。
- 本次不修改 `src/codex-skin.mjs` 的行为，也不自动切换本机正在运行的其他引擎。
- 不要让两套控制器同时向同一个 Codex 窗口注入样式。停止、卸载或迁移现有控制器需要单独确认范围。
- 新预览验证的是启动器名称与布局，不冒充完整主题应用测试；更名本身不证明所有 Codex 版本均兼容。
- 2026-09-29：独立引擎增加最后写入优先保护。守护器在注入前复核主题 ID 和保存时间，过期轮询不会覆盖较新的图片选择；这与另一套主题菜单控制器的修复思路一致，但没有迁移其代码或运行状态。

## 本版验证

- Skill 结构校验、Node 语法检查和 Windows PowerShell 5.1 解析通过；启动器保留 UTF-8 BOM。
- 使用实际 WinForms 控件离屏渲染并目视核对标题、布局和文字；检查初始应用按钮禁用、启用/禁用切换及连接状态标签。为处理 DrawToBitmap 的 PictureBox 叠放限制，前景控件按实际坐标最后绘制，预览不是桌面屏幕截取。
- 引擎源码和 PowerShell 引擎封装没有行为修改；本次不执行 Apply/Restore，不覆盖另一个正在运行的控制器。并未重新验证换肤全链路。
- 发布包按明确的17文件清单构建，不包含运行时状态、用户图片、日志、备份或 Git 元数据；旧截图和提交历史保留用于回退。
